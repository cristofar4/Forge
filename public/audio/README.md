# Audio tracks

Drop a licensed MP3 here named after the song id to have the robot play the real
track. If a file is missing, the site plays a genre matched beat synthesized in
the browser instead (no copyright concern), and the robot still dances in the
right style.

| File to add            | Song           | Style    |
| ---------------------- | -------------- | -------- |
| `boombap.mp3`          | Boom Bap       | hip hop  |
| `all-my-life.mp3`      | All My Life    | hip hop  |
| `trap.mp3`             | Trap Mode      | trap     |
| `westcoast.mp3`        | West Coast     | hip hop  |
| `naija.mp3`            | Naija Hip Hop  | afro     |
| `afrobeats.mp3`        | Afrobeats      | afro     |
| `amapiano.mp3`         | Amapiano       | amapiano |

Example: to play the real "All My Life", add `all-my-life.mp3` to this folder.
Only add music you have the rights to use.
